This browser cannot talk to the unit. Web MIDI needs a Chromium-based browser — Chrome, Edge, Opera, Brave, Arc, Helium, Vivaldi and the rest of them. Safari and Firefox have no implementation, so ports will not appear. Browsing and decoding a .syx file works here regardless.

      What the unit has to be doing

      Backup and restore need the unit stopped and on the SysEx config page: SHIFT + TEMPO to type / select. That is where the firmware listens; anywhere else, requests are ignored. Entering the page flushes pending edits to EEPROM and leaving it reloads the current bank, so a restore takes effect without a power cycle.

      Flashing needs the unit in bootloader mode: stop the sequencer, SHIFT + TEMPO to the BOOTLOADER page, then SHIFT + encoder. The panel goes dead afterwards — it is no longer running the firmware — and the unit restarts on its own when the transfer finishes.
